# Concept 8: Give AI the Job Again

---

## The Core Idea

Real jobs come back — the same report every week, the same comparison every month.
**Repetition is a need.** And it asks for two things:

1. A place to store context AI keeps needing
2. A way to run the job without retyping everything

---

## Do It Now

**Step 1:** Copy your complete brief into a note **outside the chat** — a text file, a notes app, anywhere you control.

**Step 2:** Open a fresh chat. Run the brief again, exactly as it is.

**Step 3:** Put the new result beside the last one. **Mark every difference.**

---

## What Just Changed?

> Nothing in the brief changed — and the result did.

Two kinds of differences exist:

| Type | What Caused It | Example |
|------|---------------|---------|
| **The world changed** | A course closed, a price moved | Link now returns 404 |
| **AI chose differently** | Different source found, different order | New course appeared in the table |

> Telling the two apart is the beginning of **running a job** — rather than doing it once.

---

## What Repetition Asks For

### 1. A Place for Context That Does Not Change

The third time you paste the same background, the same source, the same rules — **stop pasting.**

Put them somewhere AI reads by itself.

That place is a **Project.**

| Term | What It Is |
|------|-----------|
| **Project** | A space that holds your files and standing instructions — every chat inside starts already informed |
| **Knowledge** | The files the Project holds — sources AI may read in every chat |
| **Standing Instruction** | A rule written once — AI follows it in every chat inside the Project |

**Example standing instruction:**
```
Mark anything you could not confirm as "unverified".
```

Written once. Applied every time. Never retyped.

### The Rule for What Goes Where

```
Instructions  →  rules that do not change
Knowledge     →  sources that do not change
Project       →  one stream of work
Chat          →  today's job
```

---

### 2. A Clock

The second thing repetition asks for is **scheduling** — so the job runs without you starting it.

| Assistant | Scheduling |
|-----------|-----------|
| **ChatGPT** | Scheduled tasks — available on paid plans |
| **Claude** | Also a paid-plan feature |

> This course does not depend on either.
> The brief you saved today is the thing you will eventually schedule.

> A job that ran is **not** the same as a job that worked.
> Apply Concept 10 (Verify) to every result that arrives on its own.

---

## Stored Context Is a Responsibility

> What you put in a Project stays there — and **shapes every answer inside it.**

Both assistants also keep their own **memory** about you, if memory is switched on.

**Once a month, check both:**

| What to Check | What to Do |
|--------------|-----------|
| What you stored in the Project | Remove anything no longer true |
| What AI remembered about you | Read, edit, or delete in settings |

> A wrong line in a Project is a wrong line in **every result the Project produces.**

---

## What to Notice

After comparing the two runs, ask:

- Of the differences you marked — which were **the world changing** and which were **AI choosing differently?**
- Which lines did you retype unchanged? → Those belong in a **Project**
  - As **knowledge** if they are sources
  - As **instructions** if they are rules
- What would you need to see next week to know the job **still worked?**

---

## Verify Before You Accept

Pick **one fact that changed** between the two runs.
Open the page. Ask:

| Question | Possible Answer |
|----------|----------------|
| Which run was right? | Both can be — if the world moved between them |
| When did it change? | Write down which run and when |

> Write it down. This is your record of a job running over time.

## Your Turn

### If Your Plan Has Projects:

**Step 1:** Create a Project for your running job.

**Step 2:** Put the source text in it as **knowledge.**

**Step 3:** Write one line as a **standing instruction:**
```
Mark anything you could not confirm as "unverified".
```

**Step 4:** Run the brief from inside the Project — **with that line removed from the brief.**

**Step 5:** Check that the `unverified` marks still appear.

### If Your Plan Has No Projects:

> Your saved note does the same work — by hand.
> Paste the context first, then the job.
> Either way, the next run should need **one message, not three.**
